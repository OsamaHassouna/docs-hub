<Aside type="note" title="Porting in progress">
Templates are being prepared for download. In the meantime, the original templates are available in the [email-docx repo](https://github.com/OsamaHassouna/email-docx) as raw HTML files (`temp-1.html`, `temp-2.html`, `Email-template-docx.html`).

Templates planned for this section:

- **Minimal transactional** — one-column, single CTA. Order confirmations, password resets, verification.
- **Newsletter** — two-column-collapse mobile, multiple content blocks, footer with social icons.
- **Announcement** — hero image with VML fallback, single bulletproof button, footer.
- **Receipt / invoice** — itemized table, totals, branded header.

Each template will include the full head boilerplate, RTL toggle, dark mode hints, and pass the [production checklist](/email-playbook/production/gmail-clipping/).
